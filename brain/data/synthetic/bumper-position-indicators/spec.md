# spec: Front Bumper with position lamps and direction indicators

## Product Type

Front bumper — exterior front-end protective assembly with integrated LED light strips combining front position lamps and front direction indicators (LH and RH).

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Front position signalling (front position lamp)
- Turn signalling (front direction indicator)
- Aerodynamic and styling cover

## Main Parts

- Bumper cover (fascia)
- Energy absorber (foam)
- Bumper beam
- Lower grille
- Front position lamp
- Front direction indicator
- Lamp control electronics and wiring harness

## Materials

| Component         | Typical material(s)                  |
| ----------------- | ------------------------------------ |
| Bumper cover      | PP/EPDM-T20, painted                 |
| Energy absorber   | EPP foam                             |
| Bumper beam       | Aluminium extrusion or HSS           |
| Lower grille      | ABS / PC-ABS                         |
| Light guide       | PMMA                                 |
| Outer lens        | PC, clear, hard-coated               |
| Light source      | LED modules on PCB                   |
