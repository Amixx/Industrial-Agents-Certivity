# spec: Front Bumper with fog lamps

## Product Type

Front bumper — exterior front-end protective assembly with integrated front fog lamps (LH and RH) in the lower bumper corners.

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Fog illumination (front fog lamp)
- Aerodynamic and styling cover

## Main Parts

- Bumper cover (fascia)
- Energy absorber (foam)
- Bumper beam
- Lower grille
- Front fog lamp, LED, with bezel
- Wiring harness and connector

## Materials

| Component         | Typical material(s)                  |
| ----------------- | ------------------------------------ |
| Bumper cover      | PP/EPDM-T20, painted                 |
| Energy absorber   | EPP foam                             |
| Bumper beam       | Aluminium extrusion or HSS           |
| Lower grille      | ABS / PC-ABS                         |
| Fog lamp lens     | PC, hard-coated                      |
| Fog lamp housing  | PBT-GF30                             |
| Light source      | LED module on PCB with heat sink     |
