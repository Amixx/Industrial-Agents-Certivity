# spec: Front Bumper with sensors and fog lamps

## Product Type

Front bumper — front-end module with integrated front fog lamps, front position lamps and parking-assist ultrasonic sensors.

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Fog illumination (front fog lamp)
- Front position signalling (front position lamp)
- Parking assistance (ultrasonic sensors)

## Main Parts

- Bumper cover
- Energy absorber
- Bumper beam
- Front fog lamp
- Front position lamp
- Ultrasonic parking sensors with wiring harness
