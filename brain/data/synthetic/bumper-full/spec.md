# spec: Front Bumper module

## Product Type

Front bumper module — exterior front-end assembly delivered ready to fit, with integrated daytime running lamps, front fog lamps, parking sensors, a front radar sensor and a front camera.

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Daytime signalling (daytime running lamp)
- Fog illumination (front fog lamp)
- Parking assistance (ultrasonic sensors)
- Forward object detection for emergency braking (radar)
- Surround view (front camera)

## Main Parts

- Bumper cover (fascia)
- Energy absorber (foam)
- Bumper beam
- Lower grille with active grille shutters
- Daytime running lamp
- Front fog lamp
- Ultrasonic parking sensors
- Radar sensor with bracket
- Front camera
- Wiring harness

## Materials

| Component         | Typical material(s)                  |
| ----------------- | ------------------------------------ |
| Bumper cover      | PP/EPDM-T20, painted                 |
| Energy absorber   | EPP foam                             |
| Bumper beam       | Aluminium extrusion or HSS           |
| Lower grille      | ABS / PC-ABS                         |
| Lamp lenses       | PC, hard-coated                      |
| Light source      | LED modules on PCB                   |
| Radar sensor      | Radar MMIC on PCB, PBT housing       |
