# spec: Front Bumper with radar

## Product Type

Front bumper — exterior front-end protective assembly with a long-range radar sensor mounted behind the bumper cover, used by the vehicle's advanced emergency braking and adaptive cruise control.

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Forward object detection for emergency braking (radar)
- Aerodynamic and styling cover

## Main Parts

- Bumper cover (fascia) with radar-transparent zone
- Energy absorber (foam)
- Bumper beam
- Lower grille
- Radar sensor (77 GHz) with bracket
- Wiring harness and connector

## Materials

| Component         | Typical material(s)                       |
| ----------------- | ----------------------------------------- |
| Bumper cover      | PP/EPDM-T20, painted (radar-compatible)   |
| Energy absorber   | EPP foam                                  |
| Bumper beam       | Aluminium extrusion or HSS                |
| Lower grille      | ABS / PC-ABS                              |
| Radar bracket     | PA6-GF30                                  |
| Radar sensor      | Radar MMIC on PCB, PBT housing            |
