# spec: Front Bumper with parking sensors

## Product Type

Front bumper — exterior front-end protective assembly with four ultrasonic parking sensors mounted in the bumper cover.

## Vehicle Category

M1 — passenger car.

## Function

- Low-speed impact protection (front protective device)
- Pedestrian protection (lower leg impact zone)
- Parking assistance (ultrasonic obstacle detection)
- Aerodynamic and styling cover

## Main Parts

- Bumper cover (fascia)
- Energy absorber (foam)
- Bumper beam
- Lower grille
- Ultrasonic parking sensors with brackets
- Sensor wiring harness

## Materials

| Component         | Typical material(s)                  |
| ----------------- | ------------------------------------ |
| Bumper cover      | PP/EPDM-T20, painted                 |
| Energy absorber   | EPP foam                             |
| Bumper beam       | Aluminium extrusion or HSS           |
| Lower grille      | ABS / PC-ABS                         |
| Sensor brackets   | PP-GF20                              |
| Sensor            | Piezo transducer, aluminium membrane |
