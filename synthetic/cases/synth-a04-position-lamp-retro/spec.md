# spec: Rear Position Lamp with Retro-Reflector

## Product Type

Rear position lamp with integrated retro-reflector — rear signalling module combining a light-emitting position function and a passive retro-reflector in one housing.

## Vehicle Category

M1 — passenger car. UNECE lighting regulations referenced apply across M and N categories.

## Function

- Rear position signalling (presence/visibility)
- Passive conspicuity (retro-reflector)
- Light transmission & color definition (outer lens)

The stop lamp and the reversing lamp are separate components elsewhere on the vehicle.

## Main Parts

- Rear position lamp
- Retro-reflector
- Outer lens
- Housing
