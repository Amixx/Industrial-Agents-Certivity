# spec: Rear Position and Reversing Lamp

## Product Type

Rear lamp — body-mounted lighting & signalling module combining the rear position function and the reversing function in a single housing.

## Vehicle Category

M1 — passenger car. UNECE lighting regulations referenced apply across M and N categories.

## Function

- Rear position signalling (presence/visibility)
- Reversing illumination
- Light transmission & color definition (outer lens)

The stop function is provided by a separate lamp. No retro-reflector is integrated in this lamp.

## Main Parts

- Rear position lamp
- Reversing lamp
- Outer lens (red section and clear section)
- Housing
