# spec: Stop/Tail Lamp

## Product Type

Stop/tail lamp — rear lighting & signalling module combining the rear position function and the stop function in a single housing with a common outer lens.

## Vehicle Category

M1 — passenger car. UNECE lighting regulations referenced apply across M and N categories.

## Function

- Rear position signalling (presence/visibility)
- Braking indication (stop lamp)
- Light transmission & color definition (outer lens)

The direction indicator, reversing lamp and rear fog lamp are housed in the rear bumper and are not part of this component. The vehicle uses separate bumper-mounted retro-reflectors.

## Main Parts

- Rear position lamp
- Stop lamp
- Outer lens
- Housing with integrated reflector
