# spec: Rear Combination Lamp (RFQ summary)

## Product Type

RCL (rear combination lamp), LH and RH, for a compact passenger car. Supplier scope: complete lamp assembly delivered ready to fit, including electronics and harness connector.

## Vehicle Category

M1. Market: EU (UNECE type approval required).

## Function

The lamp provides the following signals and features:

- Tail light (on together with the headlamps / parking light)
- Brake light
- Back-up light (white, active in reverse gear)
- Red reflex reflector integrated behind the outer lens
- Styling: red outer lens with clear inner optics

## Main Parts

- Tail light optics
- Brake light optics
- Back-up light optics
- Reflex reflector
- Outer lens
- Housing, gasket and clips
