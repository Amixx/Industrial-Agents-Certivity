# spec: Rear Position Lamp

## Product Type

Rear position lamp — slim LED lamp with a light-guide optic, providing only the rear position function.

## Vehicle Category

M1 — passenger car. UNECE lighting regulations referenced apply across M and N categories.

## Function

- Rear position signalling (presence/visibility)
- Light transmission & color definition (outer lens)

Stop, reversing, direction-indicator and retro-reflector functions are provided by other components on the vehicle.

## Main Parts

- Rear position lamp (light guide)
- Outer lens
- Housing

Representative values — confirm against actual bill of materials.
